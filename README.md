# BELENTANI_OS // JUDAS-CORE

Creative OS web del universo Judas.

## Qué es

El **sistema operativo creativo** de la obra: la capa que organiza, no la obra en sí. Next.js
como base, con el organismo Judas alrededor.

En línea: sin publicar — GitHub Pages no está activo en repositorios privados.

## Stack

- **Vite y React** — aplicación
- **TypeScript** — tipado
- **Vercel** — despliegue (`vercel.json`, salida `dist/public`)

## Configuración

Hay `.env.example`: copiar a `.env` y rellenar. Ningún secreto se versiona.

## Documentación

`STORY.md` cuenta la narrativa de la obra. Es el punto de entrada para entender qué se está
construyendo y por qué.
